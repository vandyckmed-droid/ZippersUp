12-1 momentum = ln(Pt−1m / Pt−12m) on dividend-adjusted EOD closes, skipping the most recent month. Raw data lives in the data repo: fmp/universe.csv, fmp/eod-adjusted/SYMBOL.csv, manifest.json. Rankings are computed here, never stored.
